# Personal Portfolio Website

A modern, responsive one-page portfolio website with a dark theme and animated background effects.

## 🚀 Features

- **Dark Theme Design** - Sleek gradient-based dark theme with purple and blue accents
- **Animated Background** - Dynamic floating gradients and particle effects
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Smooth Animations** - Fade-in effects, hover animations, and gradient shifts
- **Social Links** - Quick access to LinkedIn and GitHub profiles
- **Contact Information** - Email and phone number with clickable links

## 🛠️ Technologies Used

- HTML5
- CSS3 (with custom animations and gradients)
- Font Awesome Icons

## 📋 Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/kassemtaha/PersonalWebsite.git
   cd PersonalWebsite
   ```

2. Open `index.html` in your web browser:
   ```bash
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # On Windows
   start index.html
   ```

## 🔧 Customization

Update the following in `index.html` with your personal information:

- **LinkedIn URL** (line 26): Update `href="https://linkedin.com/in/kassemtaha"`
- **GitHub URL** (line 31): Update `href="https://github.com/kassemtaha"`
- **Email** (line 40): Update `href="mailto:your.email@example.com"` and the display text
- **Phone Number** (line 44): Update `href="tel:+1234567890"` and the display text

## 🎨 Styling

All styles are contained in `styles.css`. You can customize:
- Color scheme by modifying CSS variables in `:root`
- Animation speeds by adjusting `animation-duration` values
- Layout and spacing in the respective sections
